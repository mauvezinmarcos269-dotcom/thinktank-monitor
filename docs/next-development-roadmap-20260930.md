# 下一阶段开发清单

更新时间：2026-10-04

本文用于承接当前平台体检、配置统一、页面优化和设置页拆分后的后续开发。原则是继续保持“小批量、可解释、可复核”，不要为了扩展来源而降低报告质量门槛。

## 一、短期稳定化

1. 保持 Brookings、CFR、CSIS、PIIE、RAND、Carnegie、Atlantic Council、AEI、ECFR 小批量试运行。
2. 每次每个来源最多新增 1 篇报告，并在前端完成复核。
3. 抓取运行日志统一使用 logger，后续排查时优先按 `source_id`、`crawl_run_id` 和候选 URL 定位。
4. 每周汇总一次新增报告、AI 失败、来源失败、候选跳过原因和复核结果。
5. Brookings / RAND RSS 只读核验及用户确认后的停用已完成，见 [rss-entry-audit-20261002.md](rss-entry-audit-20261002.md)：RSS `52`、`54` 已停用，网站源 `1`、`7` 和历史记录保留，未直接替换为空的 RAND China Atom feed；前端需处理数量由 48 降为 46。
6. 定时与提醒只读核验及第一步代码修复已于 2026-10-04 完成，见 [schedule-notification-audit-20261004.md](schedule-notification-audit-20261004.md)：将代码中的每日检查改为每 5 分钟检查到期来源，补齐批次/来源互斥、锁内复查、准入过滤和批次结果统计。现有来源频率未变更；231 项后端测试和真实 PostgreSQL 只读事务锁验证通过。尚未重启服务或执行新版调度的运行验收，实际采集频率、自动 AI 边界和网站覆盖率须另行确认。
7. 停用来源提示已于 2026-10-03 统一：使用独立灰色停用提示，明确机构准入与来源启停的区别，标注停用前错误与原抓取频率。四个停用来源、正常网站源和历史候选查看均完成页面核验，来源配置未变更。

七个美国重点网站源的桌面候选卡片与筛选已完成走查，统计和验收边界见 [source-rollout-status.md](source-rollout-status.md) 的“2026-10-02 美国重点网站源页面验收汇总”。AEI、ECFR 和移动端仍需另行安排本轮页面走查。

建议优先做只读审计，不直接写入正式报告库：

1. Chatham House：复核已有解析能力是否适配当前页面结构。

3. JIIA / RIETI / ERIA：作为周边和区域经济来源试点，先确认英文出版物入口。

每个来源升级前必须留下证据链：入口 URL、只读候选、文档检查结果、涉华判断结果、人工抽样结论和是否允许 `pilot_crawl`。

## 三、AI 成果质量

1. 抽样检查全文翻译是否存在漏译、压缩、摘要化或段落错位。
2. 继续校验“主要观点”是否达到 1500-2000 字、4 个以上分论点。
3. 继续校验“深层研判”是否达到 2000-2500 字、4 个以上分论点。
4. 将老师复核意见归类为提示词改进项，例如“政策建议不足”“战略意图分析偏浅”“原文观点与评论混淆”。
5. 对反复失败的长报告，优先检查分块长度、模型超时、finalizer 重试和内容哈希是否匹配。
6. 教师账号与 AI 外发边界只读审计已完成，见 [teacher-ai-boundary-audit-20261004.md](teacher-ai-boundary-audit-20261004.md)：当前只有管理员账号；涉华判定本身也会发送正文或抽样到 LLM，`skipped` 不覆盖这一阶段。自动调度、重试和实际执行尚无持久化外发授权校验。优先确认并补齐抽样/全文分离的授权控制，再进行新版调度受控启用验收，不自动授权历史报告。
7. 用户确认后，已实现默认关闭外发、抽样/全文分别持久化审批与撤销、调度和实际 HTTP 请求前检查，以及候选“待授权”展示，见 [llm-authorization-implementation-20261004.md](llm-authorization-implementation-20261004.md)。正式库尚未迁移，外发尚未开启，正式进程尚未统一切换。实施复核同时更正：当前 pilot 脚本本身不调用涉华 LLM，而是直接入库，其准入逻辑待单独处理。
8. 隔离部署验收已于 2026-10-05 完成：修复空库历史迁移缺列，验证授权迁移升级/回滚/再升级、零历史授权、外发关闭的 API/Worker/Beat 实际链路和五分钟定时投递；临时数据库、Redis 与进程已清理。正式库迁移和统一服务切换仍待单独确认，见 [llm-authorization-deployment-acceptance-20261005.md](llm-authorization-deployment-acceptance-20261005.md)。
