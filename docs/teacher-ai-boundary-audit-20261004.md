# 教师账号与 AI 外发授权边界核验

核验日期：2026-10-04。数据库快照时间：16:38:43（北京时间）。

## 一、范围与结论

本轮只读检查账号、权限、通知收件人及 LLM 调用入口，并执行隔离的权限验证和现有单元测试。未创建账号、修改角色或配置、投递采集或 AI 任务、发送报告正文、重启 Worker / Beat。

结论：**尚不具备教师复核闭环和逐篇 AI 外发授权保障，不应直接进入新版调度启用验收。** 现有定时 AI 调度并未因本轮审计而停止；“没有处理中报告”的数据库快照不能证明消息队列为空或后续不会调用 LLM。

## 二、账号与提醒

当前数据库只有 1 个启用的管理员账号，没有教师账号，也没有发给教师的通知记录。账号信息核验仅记录角色、启用状态和数量，不输出邮箱、密码或令牌。

| 操作 | 当前教师权限 | 代码依据 |
| --- | --- | --- |
| 查看报告、成果、复核历史与导出 | 允许，要求有效登录 | `backend/app/api/v1/reports.py` |
| 查看和标记自己的通知 | 允许，按当前用户 ID 限制 | `backend/app/api/v1/notifications.py` |
| 提交单篇复核状态和意见 | 不允许，管理员专属 | `reports.py` 的更新接口 |
| 批量复核 | 不允许，管理员专属 | `reports.py` 的 `batch-review` |
| 重试 AI、重新提取正文、删除报告 | 不允许，管理员专属 | `reports.py` |
| 管理来源或手动采集 | 不允许，管理员专属 | `backend/app/api/v1/sources.py` |

鉴权依据是数据库中的当前用户角色与启用状态，不是直接信任 JWT 中的角色声明。现有登录接口只有登录和查询当前用户；`create_superuser.py` 只创建管理员，未找到教师账号管理接口或专用创建工具。

前端 `frontend/app/reports/report-detail-article.tsx` 将 `canReview` 绑定到 `canRetryAI`，两者都仅对管理员开放。因此不是单纯隐藏了教师按钮，后端也拒绝教师复核。

通知收件人另有不一致：

- 新报告和每日摘要面向所有启用用户。
- AI 最终成功通知仅面向 `teacher`，文案为“报告翻译与评论已完成，请复核”。当前没有教师，因此不会形成教师收件记录。
- 达到重试限制后的 AI 失败通知面向管理员。
- 当前教师即使收到成功通知，也不能提交复核意见。

建议待确认后开放“教师查看、导出、单篇/批量复核”，保留管理员对来源、正文维护、删除和 AI 外发审批的控制。不能简单给教师开放通用报告 PATCH：其 `ReportUpdate` 还包含标题、来源、URL、正文及正文哈希等字段。应使用仅包含复核字段的接口和 schema，并将前端 `canReview` 与 `canRetryAI` 分离。

## 三、LLM 调用边界

运行中 `thinktank-celery-worker` 的脱敏配置为：

| 项目 | 实际读取值 |
| --- | --- |
| LLM 类型 | `openai_compatible` |
| LLM 主机 | `api.siliconflow.cn` |
| 模型 | `Qwen/Qwen3-14B` |
| API 密钥 | 已配置，仅核验布尔值 |
| Worker 队列 | `celery` |
| 每日摘要 | 开启 |
| 即时外部提醒、邮件 | 均关闭 |
| 邮件收件人、企业微信、飞书 | 均未配置 |

这是运行中 Worker 的配置读取，不是成功连接测试，也不能据此证明所有其他进程均使用相同配置。未读取或输出密钥及完整环境变量。

### 1. 涉华判定本身就会外发内容

`backend/app/services/ai/report_relevance_service.py` 的 `evaluate_china_relevance` 会调用 LLM：正文不超过 12000 字符时发送全部正文；更长时发送开头、中部、结尾各 4000 字符，加上标题、段落标识和提示词。

常规 `backend/app/services/crawler_service.py` 会在报告入库之前调用此判定，不能仅靠后续报告的 AI 状态阻止这次外发。只按已入库的 `report_id` 审批也无法覆盖此入口。

更正（2026-10-04 实施时复核）：当前 `backend/app/scripts/pilot_crawl_sources.py` 实际没有调用涉华判定，而是文档检查后直接入库；此前将它也列为抽样外发入口不准确。该脚本的 `--ai-status skipped` 不触发全文生成，`pending` 则可能被后台 AI 调度选中。脚本的涉华准入流程应单独核验，不能将文档合格等同于已完成涉华判定。

### 2. AI 任务状态不是外发授权

| 入口 | 现有行为 | 缺口 |
| --- | --- | --- |
| 自动采集入库 | 新报告进入 `pending` | 无单独外发批准记录 |
| 正文重新提取、重置脚本 | 可将报告改回 `pending` | 可能再次被周期调度选中 |
| 每 5 分钟的 AI 分块调度 | 选择可处理/可恢复的报告并投递 | 按状态和重试条件，不按授权选择 |
| 管理员 `retry-ai` | 重置状态并直接投递指定报告 | 有角色鉴权，无明确外发同意记录 |
| 分块执行 | 校验状态、正文哈希和文本范围后调用 LLM | 哈希保证内容一致，不代表获准外发 |
| 汇总与评论 finalizer | 将报告标题及分析笔记等交给 LLM | 派生成果外发同样未校验授权 |
| 自动重试、过期恢复、旧任务兼容入口 | 能重新进入分块或 finalizer | 不能只在前端或首次入队时检查 |
| `rerun_report_ai_chunks.py` 等直接执行脚本 | 可直接调用执行器 | 不能仅依赖 Beat 的开关 |

核验依据包括 `backend/app/workers/report_tasks.py`、`ai_tasks.py`、`services/ai/report_ai_chunk_runner.py`、`report_ai_chunk_service.py`、`report_ai_finalizer_runner.py`、`api/v1/reports.py` 和相关维护脚本。

`Report` 模型及数据库表未发现外发授权主体、范围、内容版本、目标端点、审批时间或撤销状态；也未找到独立授权表。现有配置没有全局 LLM 禁用或逐篇审批模式。`only_report_id` 是调度范围过滤条件，不是授权凭证；成果“复核通过”也不能代替原文外发授权。

此前聊天中对报告 `441`、`442` 的逐篇授权不能扩展为其他报告、整个来源或涉华抽样的长期授权。本轮未修改其历史成果，也未补写任何推定授权。

## 四、建议分步实施（均待确认）

1. **先补外发授权控制。** 默认不自动外发，区分“涉华判定抽样”和“全文翻译/分析及派生成果汇总”。持久化授权人、时间、内容哈希、用途范围和目标端点/模型；正文、端点或范围变化后重新确认。不自动为历史报告补授权。审批前可以抓取/提取文档，但需保留待判定状态，不能绕过涉华质量门槛直接纳入合格报告。
2. **覆盖入队和执行端。** 自动/手动入口、分块、finalizer、旧消息、重试、恢复及直接执行脚本均在实际请求前检查。撤销后阻止后续请求；已发出或进行中的请求不能宣称已撤回。补充未授权无网络请求、范围错误、内容变更、撤销后重试等测试。
3. **再完善教师复核与账号交付。** 确认教师职责后添加窄范围复核接口与独立前端权限；用本机交互输入密码的方式创建教师账号，不在聊天或日志中收集明文密码。验证老师能复核但不能修改正文、抓取来源或自行外发 AI。
4. **最后进行运行验收。** 明确是否允许自动涉华抽样以及提醒收件人，确认运行进程版本一致；处理旧 Worker/旧任务的衔接后才启用新版调度。先验证未授权任务被拦截，再对单篇明确授权报告验证采集、处理、通知、教师复核全过程。修改采集频率、重启或启用外部渠道均另行确认。

以上是建议，不是已实施的功能。来源级自动抽样与逐篇全文生成必须分别获得确认，不能将“继续开发”理解为长期外发授权。

## 五、验证与证据

- PostgreSQL 使用 `REPEATABLE READ, READ ONLY` 事务，实测 `transaction_read_only=on`，最后回滚；仅查询角色统计、状态统计、最近报告 ID 和表结构，不查询正文或密钥。
- 内存 FastAPI `TestClient` 模拟教师，验证单篇复核、批量复核、重试 AI、提取正文、采集、删除六个接口均返回 403；数据库依赖被替换为任何操作都会报错的对象，不访问真实 HTTP 写接口。
- 现有 `test_security.py`、`test_ai_tasks.py`、`test_report_ai_chunk_service.py`、`test_notification_service.py` 共 19 项通过。它们证明相应现有行为未失败，不证明缺失的授权机制已实现。
- 本轮仅新增核验脚本/证据/文档及更新路线图，无业务代码修改、新依赖或配置变更；未重跑本轮无改动的前端页面验收。
